# v2.4.2 · 授权完成，运维继续

从一次性授权窗口，延伸到持续可用的槽内人工运维入口。完成登录后，凭据立即保存，原浏览器继续保留，方便处理续费、手动导出 Session、领取活动权益及其他账号操作；关闭浏览器和卸载运行环境，由操作者自行决定。

## 原窗口继续操作，原环境继续保持

- **授权落库，窗口保留**：收到有效 OAuth 回调后立即换取并保存凭据，释放一次性回调监听端口；同一个 Chromium 进程、私有图形显示、profile 和远程输入管道继续工作。
- **槽位环境贯穿后续操作**：继续使用当前槽位的代理出口、网络、语言、时区及浏览器会话；不把会话搬到面板机或本机浏览器。
- **离开页面也能回来接管**：离开详情页不再自动发送取消，可返回原槽重新连接；授权成功后不按空闲时间自动关闭窗口。
- **授权结果与窗口退出分开处理**：后续手动关闭、取消或浏览器异常不会把已经保存的授权改成登录失败；资源恢复异常仍单独提示。
- **状态及时刷新**：保存成功即刷新槽位及账号池状态，无需等到浏览器退出。窗口打开期间阻止改绑、重复登录和环境维护，避免覆盖正在使用的账号会话。

## Session 页面与手动导出

远程屏幕新增 **「Session 页面」**，直接在当前槽位浏览器打开 `https://chatgpt.com/api/auth/session`。确认 ChatGPT 网页已登录后，可在远程画面按 Ctrl+A、Ctrl+C，再使用「读取远程剪贴板 / 复制到本机」手动导出。

此入口不自动抓取、保存或发送 Session 到第三方。Codex OAuth 授权成功本身不保证 ChatGPT 网页会话也已登录；续费和活动权益操作仍由操作者在官网完成。

## 资源由用户掌控

**「关闭浏览器」**停止进程并恢复临时 Docker 内存、swap 和 CPU 限制，运行文件及会话资料保留；之后可自行选择 **「卸载浏览器环境」**节省槽位磁盘。卸载保留凭据、profiles、缓存和配置，后续可按需安装。

浏览器保留期间仍占用运行资源及全局浏览器任务锁。请完成操作后主动关闭，再使用其他槽位的浏览器。槽位关机、控制面重启、相关配置变更或显式停止仍会终止进程；未完成授权的登录超时和后台自动重登退出行为保持原规则。静置但已开机的槽位可手动维护浏览器环境，不自动开启调度。
