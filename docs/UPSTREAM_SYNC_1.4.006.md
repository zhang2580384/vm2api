# v1.4.006 选择性同步与协议观察记录

2026-10-31 的独立集成候选进展见 [Claude 协议候选验收](CLAUDE_PROTOCOL_CANDIDATE.md)。下面保留 v2.1.0 当时的同步范围与决策，不代表当前自有版本的全部功能。新候选仍被原生缓存 TTL 行为阻断，尚未发布。

## 决策与版本边界

采用稳定优先方案：同步调度、配额、生命周期和出口恢复，Claude 协议保留 v2.0.2 / v1.3.226 的兼容实现，观察新版协议的后续修复后单独验收。v2.1.0 是选择性同步版，不与上游 v1.4.006 完整等价。

- 自维护起点：v2.0.2，`111447f7d79f5d6311c518a4efb4ef6da614704d`。
- 上游同步目标：v1.4.006，`07edb2cdc0576da1ea9a64bc2d27c00fb4c15aff`。
- 完整协议预览：`sync/upstream-v1.4.006-protocol-preview`，`567cc63`；供差异和复测参考。
- 稳定合并：PR #4 已合入 main（`425a742`）；保留 merge 双亲历史，随后显式恢复旧协议契约。
- payload：`payload-2026.10.24-cli-303-sdk`，逐文件核对尺寸与 SHA-256。不能只回退 Node 源码而使用新版 cli-node。

## 本次合入

- 四态调度：人工关闭、不可调度故障、临时受限与可调度分别维护；旧记录迁移前备份。
- 会话席位与设备亲和：请求结束且没有排队后续请求即释放；粘性 TTL 只保存 VM 关联，不长期占席。
- 本地 SOCKS 槽使用 `restart=no`，控制面恢复阻断规则和出口后启动；迁移失败阻止控制面启动。
- GPT 内核重载等待旧进程退出并使用当前代理；清除已过期的额度限制。
- 运行目录权限、域名转发、删除槽位清理池成员、ARM64 安装、窗口历史与费用估算修复。
- 完整 payload 变化检测与远程集群检查保留；检测改进不意味着采用新版 Claude payload。
- 修复出口进程识别回归：验证完整配置路径，保留原生进程 PID，识别已删除二进制并等待进程回收。不同项目同 proxy ID 不得互相停止。

## 暂缓项目与理由

这些新协议变化主要针对 **Claude**；不阻止独立的 GPT 运行和额度修复。

| 暂缓内容 | 本版保留 | 原因与再次验收要求 |
| --- | --- | --- |
| 零注入改为仅保留计费头、提示词重组 | 旧预设及调用方 system 处理 | 会改变已有请求语义；核对各预设、官方透传、调用方 system 和注入统计 |
| `official_303` 归一到 `official_full`、统一 CLI 版本 | 原预设、CLI 版本选择及保存配置 | 避免保存设置时静默迁移；需要可验证的迁移和回退 |
| 新环境消息布局、时区/语言/长环境说明开关、模板角色 | 旧模板变量和按档开关、匹配的前端预览 | 前后端必须一致，不能改变已关闭环境注入的含义 |
| 缓存锚点、图片历史裁剪与断点重写 | 旧缓存跟踪、TTL 与断点契约 | 直接改变出站消息和缓存费用；需长对话、图片、切号、错误修复回归 |
| thinking/effort 修复、beta 头和 `cc_entrypoint` 配置 | 原请求组装及 CLI 行为 | 需验证流式/非流式、classifier、重试和模型差异，并与二进制配套 |
| `auto` 模型策略与目录变化 | 旧目录及解析契约 | 与新版请求处理关联，待 API 兼容测试通过后一起评估 |
| 公共及面板 `count_tokens` 接口移除 | 原有接口和按凭据类型分流 | 删除接口会破坏现有客户端；后续单列兼容性决策，不能随依赖升级悄悄移除 |
| `payload-2026.10.26-cli-effort` 的 cli-node | 原清单 `payload-2026.10.24-cli-303-sdk` | 控制面、预设与二进制须使用同一行为契约；不修改摘要接受未知产物 |
